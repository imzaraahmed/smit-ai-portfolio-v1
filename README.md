# Aura Portfolio

Create a modern, responsive personal portfolio website using React and Tailwind CSS.

The design should look clean, premium, and professional with a dark theme, blue and purple gradient accents, smooth animations, rounded cards, and subtle shadows.

The portfolio should include these pages and sections:

• Hero

• About Me

• Skills

• Featured Projects

• AI Automation Projects

• Education

• Certifications

• Contact

• Footer

Features:

- Responsive for desktop, tablet, and mobile

- Dark/Light mode toggle

- Smooth scrolling

- Animated typing effect in Hero section

- Beautiful hover animations

- Professional icons

- Download Resume button

- GitHub button

- LinkedIn button

- Contact form

- Modern fonts

- Clean spacing and layout

Leave placeholders for my personal information because I will provide it later.
